プライバシーポリシー

Google Health Bridge（以下「本アプリ」）は、開発者本人が自分の健康データを自分のために読み取る、個人利用専用の連携サービスです。利用者は開発者本人だけです。

取得するデータ

本アプリは Google Health API を通じて、本人の Google アカウントから次のデータを読み取り専用で取得します。

  • 睡眠データ（就寝・起床時刻、睡眠ステージ、覚醒時間）
  • 心拍変動（HRV / RMSSD）
  • 安静時心拍数
  • 呼吸数
  • 血中酸素飽和度（SpO2）

利用目的

取得したデータは、本人の睡眠と疲労回復の記録・分析のためだけに使用します。広告、マーケティング、その他の目的には使用しません。

保存と管理

  • API へのアクセスに使うリフレッシュトークンは、開発者本人の Google Cloud プロジェクト内の Secret Manager に保管します。
  • 取得したデータは、開発者本人の記録としてのみ保持し、本人の許可なく外部に送信しません。

第三者への提供

取得したデータを第三者へ提供、販売、共有することはありません。

アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティによるアクセス」設定からいつでも取り消すことができます。取り消した場合、本アプリはデータを取得できなくなります。
