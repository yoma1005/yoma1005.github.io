プライバシーポリシー

このサイトおよび関連プロジェクト（以下「本プロジェクト」）は、運営者本人が趣味と技術実験のために個人で開発・運用しているものです。利用者は運営者本人だけです。

取得するデータ

本プロジェクトの一部は、外部サービスの API と連携し、運営者本人のアカウントからデータを読み取り専用で取得する場合があります。取得するデータの範囲は、各サービスの認可画面で表示される範囲に限られます。

利用目的

取得したデータは、運営者本人の個人的な記録・分析・技術検証のためだけに使用します。広告、マーケティング、その他の目的には使用しません。

保存と管理

  • API へのアクセスに使う認証情報は、運営者本人が管理するクラウド環境のシークレット管理機能に保管します。
  • 取得したデータは、運営者本人の記録としてのみ保持し、本人の許可なく外部に送信しません。

第三者への提供

取得したデータを第三者へ提供、販売、共有することはありません。

アクセスの取り消し

各サービスへのアクセス許可は、そのサービスのアカウント設定（サードパーティによるアクセス等）からいつでも取り消すことができます。取り消した場合、本プロジェクトはデータを取得できなくなります。
